АСУИР — исправление привязки оборудования и проверки комплектующих
Версия: 2026-11-03. Файлы RU и EN — полные HTML-версии для GitHub.

ОБНАРУЖЕННАЯ ОШИБКА:
В прежней версии цена линии $25 000 и выпуск 20 шт./день относились к демонстрационному сценарию. При этом кнопка «Открыть выбранную» содержала заранее подставленную ссылку Alibaba на другой товар. Это создавало ложное впечатление проверки стоимости и мощности конкретной линии.

ИСПРАВЛЕНИЯ:
1. В демонстрационном каталоге больше нет автоматически подставленной ссылки на якобы выбранное оборудование. Старую ошибочную ссылку в ранее сохранённых данных программа также не открывает как подходящую линию.
2. Стоимость $25 000 и выпуск 20 шт./день явно помечены как исходные допущения.
3. Добавлены поля «Цена по предложению» и «Производительность по предложению». Пользователь вводит параметры РЕАЛЬНОГО предложения и нажимает «Применить параметры поставщика». Значения синхронизируются с первой страницей и основным расчётом; при переналадке сохраняется ссылка на базовую линию.
4. В деталях первой страницы добавлен список комплектующих для O3 и O4 Pro с признаками доставки: «Не проверено», «Доступна (вручную)», «Недоступна в регион», «Запрос поставщику». Для каждого предложен поиск альтернативы у Alibaba. Отметки сохраняются локально в том же браузере.
5. При отметке «Недоступна в регион» результат помечается как предварительный. Без подтверждённой альтернативной цены стоимость деталей автоматически НЕ меняется.
6. Основные экономические алгоритмы, расчёты себестоимости и модуль переналадки не менялись.

ПОРЯДОК ПРОВЕРКИ:
А) Первая страница → Открыть линию → вкладка создания линии → пустая ссылка на выбранное оборудование и заметка о демонстрационных данных.
Б) Найти реальное предложение → вставить конкретную ссылку → указать цену и МОЩНОСТЬ В ШТУКАХ ЗА ДЕНЬ → Применить параметры поставщика.
В) Первая страница → Раскрыть исходные параметры → «Доставка комплектующих и альтернативные поставщики» → отметить доступность для каждого компонента.
Г) Сопоставить договорные условия поставщика, MOQ, стоимость логистики, страну производства и совместимость деталей до инвестиционного решения.

ПРОВЕРКИ:
- JS-синтаксис обеих версий: успешно.
- Интерактивный сценарий Chromium с имитацией Firebase: отображение расчётов, вход в обе линии, ввод параметров $199 999 / 100 шт./день, сохранение ссылки при переходе на O4 Pro и отображение недоступной доставки: успешно.
- Фактическую доступность Alibaba для региона пользователя и реальную работу Firebase эти проверки не подтверждают.
