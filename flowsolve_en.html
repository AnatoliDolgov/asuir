FlowSolve — a recursive problem-solving method

FlowSolve is a problem-solving method the author has applied in practice for about 45 years: problem → ideal solution → the path to it; where needed, the solution found becomes a new problem with its own ideal solution. It differs from enumeration in that a branch is chosen before it is unfolded: first one establishes what affects the event, which factors are controllable and which already exist as means; the lever lies where these meet. A standard problem is then solved within three levels.

In the ASUIR system FlowSolve is the first link. A problem that existing means can solve goes to the efficiency generator; a problem that needs new technology goes to the technology generator “Aristotle” (in development) and then to the efficiency generator.

Branch selection rules

  1. An existing means is not discarded on a general feature: first check whether a small refinement makes it reach the ideal solution.
  2. If a participant is uncontrollable, act through a controllable participant.
  3. Of the branches leading to the ideal solution, choose the one requiring the least change.

Not allowed: going down the tree without an influence table; listing every possible branch “for completeness”; turning to new or expensive technology when refining what already exists is enough.

Solution template

Fill in the steps in order; the influence table comes before any branch is chosen. Rows where a factor is controllable and already exists as a means are highlighted in green: these are lever candidates. Saved problems are kept only in this browser.

0. Problem

How the problem was first stated.

1. Exact statement

What precisely is prohibited or required. Narrow it to the essence: for example, what is prohibited is not paths crossing, but a real simultaneous crossing.

2. Ideal solution

A result achieved regardless of uncontrollable participants and chance.

3. Influence table

Everything that affects the event. For each factor: is it controllable, and does it already exist as a means? Filled in before a branch is chosen.

4. Lever

A factor that is controllable and already exists. If there is none, the factor needing the smallest addition.

5. One branch — no deeper than three levels

From the lever to the ideal solution. At each level: the problem, its ideal solution and one sentence on why this branch was chosen. A second branch is opened only if the first does not reach the ideal solution.

6. Check

Is the ideal solution reached under the worst behaviour of the uncontrollable participants?
